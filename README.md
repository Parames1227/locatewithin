# LocateWithin

LocateWithin is an AI-powered semantic location discovery platform.

The system allows users to discover places using natural language queries such as:

- "Italian restaurants in Chennai"
- "Heritage places to visit"
- "Cafes to work remotely"

This project uses:

- Spring Boot
- Elasticsearch
- Vector Search
- RAG (Retrieval Augmented Generation)
- Docker

Currently Chennai is used as the demonstration dataset.
